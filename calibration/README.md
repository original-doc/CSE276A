# 传感器标定实验记录(CSE 276A HW1 素材)

> 记录人:yuanshengqi · 2026-10-11 · 机器人:Rubik Pi 3
> 实验环境:**自习室(木地板)**——磁力计标定与磁场环境强相关,参数只对该自习室有效

## 传感器概况

电机板(串口 `/dev/ttyUSB0` @115200)内置 9 轴 IMU,每帧返回:

- `r/p/y`:roll/pitch/yaw(板子固件融合输出,yaw 为磁力计主导的绝对航向)
- `gx/gy/gz`:角速度(°/s,原始陀螺仪)
- `ax/ay/az`:加速度;`mx/my/mz`:原始磁力计(整数)

请求协议:`{"T":126}` → 回复 `{"T":1002, ...}`。实测有效数据率 **~4.5Hz**(更高请求频率下板子回显占一半,~50Hz 轰炸会导致数据管道冻结,停止后自愈)。

## 关键发现

1. **板子 yaw 在电机运转时完全不可信**:电机电流磁场污染磁力计,810° 物理转动只读出 ~2°(读数弹回)。
2. **板子 yaw 对快转有阻尼融合的"爬行/弹回"**:快转 90° 停稳后只报 15°;慢转 360° 能跟上(+394°)。
3. **板子 yaw 静止漂移极小**(0.24°/min),但静止读数随电机启停后的磁场变化漂移。
4. **gz(陀螺仪)静止噪声 std ≈ 13°/s,偏置 ≈ -1.51°/s**——纯积分 ±10-25° 误差,只能用于转动中的粗估计。
5. **结论:任何磁力计航向都不能在电机运转时使用;必须在"电机停转"状态下读航向。**

## 磁力计自标定(本目录方法)

用三轮水平 360° 慢转数据(814 采样)做 min/max 椭圆拟合:

```
cx=-14.5  cy=-15.0  sx=20.5  sy=22.0
heading(deg) = -atan2((my-cy)/sy, (mx-cx)/sx) * 180/pi   # CCW 为正
```

标定与位置/环境相关(换房间、靠近大金属物需重新标定,转一圈 20 秒)。

## 验证结果

三轮整转(标定自检):误差 5.0 / 15.5 / 1.6 度(物理角为目测,±5°)。

四轮独立半圈(180°,交替顺逆时针,水平慢转):

| 轮次 | 方向 | 自标定航向 | 误差 | 板子 yaw | 板子测到 |
|---|---|---|---|---|---|
| 1 | CW  | -167.8° | 12.2° | -41.6° | 23% |
| 2 | CCW | +168.7° | 11.3° | +43.4° | 24% |
| 3 | CW  | -173.9° | 6.1°  | -32.7° | 18% |
| 4 | CCW | +178.0° | 2.0°  | +37.1° | 21% |

平均误差 ~8°,系统性少报 ~4.5%(疑似软铁畸变残差或目测偏差,待电机实转+画线量角复核)。

快转组合(90°+180°,手抬倾斜):+110°(误差20°)、-194°(误差14°),倾斜会劣化 2D 标定。

## 推荐控制架构

```
转-停-校正循环:
  1. 粗转(积 gz)
  2. 停 0.5s(磁场稳定)
  3. 读自标定航向,算残差
  4. |残差|<容差(如 10°)→ 通过;否则小修正,回到 1
```

直线段用 gz 检测跑偏;绝对航向只在静止时读。

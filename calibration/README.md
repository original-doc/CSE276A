## 1. 背景

机器人电机板(串口 `/dev/ttyUSB0` @115200)内置 9 轴 IMU,每帧数据含:

| 字段 | 含义 |
|---|---|
| `r/p/y` | roll/pitch/**yaw**(板子固件融合输出,yaw 为磁力计主导的绝对航向) |
| `gx/gy/gz` | 原始陀螺仪角速度(°/s) |
| `mx/my/mz` | 原始磁力计(整数输出) |

协议:发 `{"T":126}` 请求 → 回 `{"T":1002, ...}` 数据帧。实测有效数据率 **~4.5Hz**(每两个请求回一帧真数据)。

队友报告的三个问题:右前轮阻力偏大;yaw 读数波动;逆时针 90° 只测到 50°。

## 2. 设计逻辑:实验链

核心思路:**每个实验只回答一个问题,结论引出下一个实验**。

```
问题1:传感器原始数据质量如何?
  └─ 实验A(静止 60s)
       → gz 噪声 13°/s、偏置 -1.51°/s;yaw 静止漂移仅 0.24°/min;10Hz 轮询安全
       → 意外发现:±0.4 命令 1.2 秒 = 物理转 810°,而 yaw 只报 2°(yaw 在电机运行时彻底失效)

问题2:电机不转时,板子 yaw 可信吗?
  └─ 实验B(手抬转 90°,3~5 秒)
       → gz 积分 ≈ +64~80°(接近真值);yaw 先跳 +30° 再"弹回",净只报 +15°
       → 结论:板子 yaw 连静止后的读数都不可信(融合阻尼 + 磁畸变)→ 必须自己标定磁力计

问题3:能用自己的标定算出航向吗?
  └─ 实验B2'(水平慢转 360° ×3 轮,采集 mx/my)
       → min/max 椭圆拟合 → 标定参数(见 §5)
       → 教训:必须水平转(悬空转 mz 波动 34,椭圆被压扁,数据作废)

问题4:自标定航向准不准?
  └─ 验证:3 圈整转 + 4 次半圈(180°,顺逆交替,水平慢转)
       → 整转误差 1.6~15.5°;半圈误差 2.0~12.2°(平均 ~8°),静止读数稳定、无弹回
       → 对照组:板子 yaw 每半圈只测到 18~24%,且停转后持续爬行

问题5:真实电机转动下,参数是什么?
  └─ E1~E6(电机实转,两版)
       → v1 假象:停转后 1.2 秒读数落在"剩磁恢复期",所有转角被低估
       → v2 修正:每个停转点采样 +0.5/+1.5/+3.0 秒 → 抓到恢复曲线 → 真参数(见 §4)
```

## 3. 关键结果

### 3.1 磁力计标定参数(本自习室有效,换环境需重标定)

```
cx = -14.5, cy = -15.0, sx = 20.5, sy = 22.0
heading(°) = -atan2((my - cy)/sy, (mx - cx)/sx)   # 逆时针为正
```

标定方法:三轮水平 360° 慢转,取 mx/my 的 min/max 作椭圆中心与半轴。

### 3.2 电机实转参数(v2,电机停转后等 3 秒读航向为真值)

| 命令值 | ω 逆时针 | ω 顺时针 | 备注 |
|---|---|---|---|
| <0.2 | ~0 | ~0 | **死区**:车只抖不转 |
| 0.3 | 73 °/s | 95 °/s | 顺快 30%(右前轮阻力:逆时针需右轮正转出力) |
| 0.4 | 177 °/s | 188 °/s | 顺快 6% |

- **剩磁恢复**:电机停转后 1.5~3 秒航向读数才可信(与命令强度正相关;0.4 档停转 0.5 秒时读数连方向都是错的)
- **gz 积分**:转弯 ≥1 秒时 ±10° 准;0.5 秒快转失效(4.5Hz 采样跟不上)
- **电池**:实验首尾探针一致,无衰减

### 3.3 验证数据摘要

- 4 次半圈(180°):自标定航向 -167.8 / +168.7 / -173.9 / +178.0°(误差 12.2 / 11.3 / 6.1 / 2.0°);板子 yaw 同期只测到 23% / 24% / 18% / 21%
- 快转组合(手抬、倾斜):误差 20°/14°——倾斜会劣化 2D 标定

## 4. 控制方案结论

```
转-停-等-读-校正循环:
  1. 转向命令必须 ≥0.3(死区以上),顺/逆时针分别查表算时长
  2. 慢转(≥1s)用 gz 积分做转动中反馈;快转只能开环
  3. 停车后等 2~3 秒(剩磁恢复)
  4. 读自标定航向,算残差;|残差| > 容差则小修正,回到 1
```

注意事项:磁力计航向只在电机停转且恢复后可信;标定参数随环境变化,换房间须重标定(转一圈 20 秒)。

## 5. 代码说明

### 通用设计模式(所有脚本共用)

- **读采样线程 + 主线程发命令分离**:采样循环独立跑,不因主流程 `sleep` 断采
- **安全兜底**:`try/finally` 保证最后发出停车命令(直连串口无看门狗)
- **`time.monotonic()` 计时**:曾因 NTP 校时跳变导致墙钟循环失控,单调时钟免疫
- **采样节奏**:请求 10Hz → 有效数据 ~4.5Hz

### mag_cal_sample.py(数据采集)

- `sampler()` 主循环:发请求 → `readline()` → `json.loads` → **过滤 `T==1002`**(回显帧不记)→ 追加 `(t, mx, my, mz, y, gz)`
- 时长由参数控制,数据落盘到指定文件

### mag_cal_fit.py(椭圆拟合与验证)

- `heading(mx, my)`:标定公式(§3.1)
- `unwrap(series)`:角度解绕——相邻差超过 ±180° 时加减 360°,把 -179°→+179° 的跳变连续化
- 拟合三方案对照:`min/max`(最终采用)/ 最小二乘圆锥拟合 / 圆锥+特征旋转
- 验证:对每轮数据算航向总变化,与物理角对照

### turn_analyze.py(单次转角分析)

- 核心思想:**只在静止时读航向**——取窗口首 3 秒与末 3 秒的航向均值,差值即转角,绕开转动中的噪声
- 另输出 `mz` 波动作水平度体检

### gyro_bias_test.py(实验A)

- 60 秒静止采样,统计 gz 均值(偏置)与标准差(噪声)
- **冻结检测**:连续两采样完全相等计数——板子被高频轮询轰炸后数据管道会冻住,此检测防患未然

### motor_cal2.py(电机实转标定 v2)

- `send(l, r)`:发 `{"T":1,"L":l,"R":r}`(±0.5 范围内,逆时针 = 左负右正)
- `read_heading(n)`:取最近 n 条记录的航向做**圆平均**(把角度转成单位向量取均值再求角,抗 ±180° 环绕)
- `delta(a, b)`:带环绕的角差 `(b-a+180)%360-180`
- `settle_reads(h0, n0)`:停转后 **+0.5/+1.5/+3.0 秒三次读航向** + 该窗口的 gz 积分——一次实验同时回答"真转角、恢复曲线、陀螺对比"三个问题
- `battery_probe(tag)`:首尾执行同一动作对比转角,检测电池衰减
- 主流程:① 死区测试——单侧驱动(如左转右停),车会绕静止侧旋转,**用航向变化判断"轮子动了没有"**,逐级加命令;② 转向标定——顺逆交替 ×2 重复,残余漂移互相抵消
